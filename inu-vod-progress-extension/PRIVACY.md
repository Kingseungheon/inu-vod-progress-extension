# 개인정보처리방침

시행일: 2026년 8월 1일

`INU 사이버캠퍼스 진도율 표시` 확장 프로그램은 사용자의 개인정보를 개발자가 운영하는 서버로 수집하거나 전송하지 않습니다.

## 처리하는 정보

확장 프로그램은 사용자가 로그인한 인천대학교 사이버캠퍼스 안에서 다음 정보를 일시적으로 읽습니다.

- 사이버캠퍼스 화면에 표시된 강좌명과 강좌 ID
- 온라인 출석부에 표시된 차시별 출석 상태(`O` 또는 `X`)

이 정보는 강좌별 진도율을 계산하고 현재 사이버캠퍼스 화면에 표시하는 목적으로만 사용됩니다.

## 저장 및 전송

- 강좌 정보와 진도율을 개발자 서버 또는 제3자 서버로 전송하지 않습니다.
- 강좌 정보와 진도율을 브라우저 저장소에 영구 저장하지 않습니다.
- 광고, 사용자 추적, 분석 도구를 사용하지 않습니다.
- 정보를 판매하거나 제3자에게 제공하지 않습니다.
- 로그인 비밀번호나 인증 쿠키를 직접 읽거나 저장하지 않습니다.

온라인 출석부 요청은 사용자가 방문 중인 `https://cyber.inu.ac.kr` 내부에서만 이루어지며, 해당 사이트의 기존 로그인 세션을 사용합니다.

## 권한과 적용 범위

확장 프로그램은 `https://cyber.inu.ac.kr`의 지정된 페이지에서만 실행되며 별도의 Chrome 권한을 요청하지 않습니다.

## 제한적 사용 원칙

확장 프로그램이 처리하는 정보는 사용자에게 강좌별 진도율을 보여 주는 단일 기능을 제공하는 데에만 사용되며, Chrome Web Store 사용자 데이터 정책의 제한적 사용 요건을 준수합니다.

## 변경 및 문의

방침이 변경되면 이 문서의 시행일과 내용을 갱신합니다. 문의사항은 [GitHub Issues](https://github.com/Kingseungheon/inu-vod-progress-extension/issues)에 남길 수 있습니다.
